BookOrbit for Android connects to a BookOrbit server and keeps supported books, audiobooks, and reading state available offline.

## Get help

- Ask a question with the [support form](https://github.com/bookorbit/bookorbit-android-support/issues/new?template=support.yml).
- Report a reproducible app problem with the [bug report form](https://github.com/bookorbit/bookorbit-android-support/issues/new?template=bug_report.yml).
- Request a feature with the [feature request form](https://github.com/bookorbit/bookorbit-android-support/issues/new?template=feature_request.yml).
- Report a problem with the server itself in the [BookOrbit server repository](https://github.com/bookorbit/bookorbit/issues/new/choose).
- Report a security or privacy concern privately through [GitHub Security Advisories](https://github.com/bookorbit/bookorbit/security/advisories/new).

Include the app's build number (shown under **More > Settings > About**), your phone and its Android version, your server version, and the steps that reproduce the problem. Do not post passwords, access tokens, or private server addresses in a public issue.

## Connection problems

Confirm that the server address opens in the phone's browser and that your BookOrbit server is reachable outside its local network when you are away from home. For a server on your home network, allow BookOrbit to find devices on local networks when Android asks. If another person operates the server, contact that administrator for account, certificate, reverse-proxy, and availability problems.

## Premium purchases

In **More**, open your account at the top, tap the **Premium** row, and choose **Restore purchases** when a completed Google Play purchase is not active on the phone. Google Play must use the same Google Account that made the purchase.

Yearly subscriptions are managed in [Google Play subscriptions](https://play.google.com/store/account/subscriptions). Google Play handles billing, refunds, payment methods, and subscription cancellation.

## Crash reports

The app does not send crash reports. When a problem needs fixing, a bug report with the app's build number and the steps that reproduce it is the most useful thing to send.

## Privacy

Read the [BookOrbit Android Privacy Policy](/android/privacy) for details about on-device data, self-hosted servers, Google Play purchases, and optional network services.
