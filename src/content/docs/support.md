BookOrbit for iPhone and Apple Watch connects to a BookOrbit server and keeps supported books, audiobooks, podcasts, and reading state available offline.

## Get help

- Ask setup and usage questions in [GitHub Discussions](https://github.com/bookorbit/bookorbit/discussions).
- Report a reproducible app or server problem with the [bug report form](https://github.com/bookorbit/bookorbit/issues/new?template=bug_report.yml).
- Request a feature with the [feature request form](https://github.com/bookorbit/bookorbit/issues/new?template=feature_request.yml).
- Report a security or privacy concern privately through [GitHub Security Advisories](https://github.com/bookorbit/bookorbit/security/advisories/new).

Include the BookOrbit iOS version, iOS or watchOS version, server version, and the steps that reproduce the problem. Do not post passwords, access tokens, private server addresses, or diagnostic archives in a public issue.

## Connection problems

Confirm that the server address opens from the same device and that your BookOrbit server is reachable outside its local network when you are away from home. If another person operates the server, contact that administrator for account, certificate, reverse-proxy, and availability problems.

## Premium purchases

Open **Settings > BookOrbit Premium** and choose **Restore Purchases** when a completed App Store purchase is not active on the device. The App Store must use the same Apple Account that made the purchase.

Yearly subscriptions are managed through [Apple's subscription settings](https://apps.apple.com/account/subscriptions). Apple handles billing, refunds, payment methods, and subscription cancellation.

## Privacy

Read the [BookOrbit iOS Privacy Policy](/privacy) for details about on-device data, self-hosted servers, App Store purchases, and optional network services.
